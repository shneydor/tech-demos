# On-call rotation

The primary on-call engineer holds the pager from Monday 09:00 UTC for seven days. A secondary is named on the same rotation and joins SEV-1 calls.

## Handoff

The outgoing engineer writes a handoff in the weekly review and links any open incidents before the pager moves.

See [[paging]] for what is allowed to page, and [[adr-021-pager-rotation]] for the decision that set the weekly cadence.
