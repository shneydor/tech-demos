# Shelf

A local reading list for one person on one machine.

What it does today:

- Save an article (title, URL, time) into the Inbox.
- Show the Inbox, newest save first.
- Archive an article, which removes it from the Inbox.

There is no snooze, no clock, and no second list. Time is not consulted. The module under `src/inbox.ts` is the seam tests already use.
